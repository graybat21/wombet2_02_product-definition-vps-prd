# WOMBET2 UI/UX 보완 태스크 (Task Breakdown)

기존 `01_TASK_리스트_추출_결과.md`는 핵심 비즈니스 로직(F1~F4) 단위로 컴포넌트를 정의했으나, 실제 프로토타입 구동을 위해 이 컴포넌트들을 담아낼 **'페이지 골격(Page Layout)'**과 **'공통 UI(Common UI)'**, 그리고 **검증 단계(Phase 0)**의 과제가 누락되어 있었습니다. 이를 보완하기 위한 태스크 리스트입니다.

## 2. 기존 Task와의 관계 및 조립 시나리오 (프로토타입 구현 관점)

위 태스크들이 구현되어야만 기존 리스트의 Task들이 정상적으로 사용자 화면에 노출될 수 있습니다. 

*   **제품 목록 시나리오**: `UI-003 (리스트 뼈대)` 위에 `F3-004 (종목 맞춤형 리스트 뷰 & 스코어보드)`가 얹어집니다.
*   **제품 상세/네거티브 시나리오**: `UI-004 (상세 페이지 뼈대)` 상단에 `F1-004 (네거티브 경고 박스)`가 삽입됩니다.
*   **핏 진단 시나리오**: `UI-004` 페이지 안에서 `F2-005 (사진 업로드 및 히트맵)`가 실행되며, 진행 상태는 `UI-006`으로 보여줍니다.
*   **구매 전환 시나리오**: `UI-005 (CTA 버튼)` 클릭 시 `F4-001 (안전 경고 팝업)`이 뜨고, 이를 통과하면 아마존 등으로 넘어갑니다.

이 보완 리스트와 기존 리스트를 결합하여 프론트엔드 프로토타입(MVP UI) 개발을 즉각적으로 시작할 수 있습니다.
